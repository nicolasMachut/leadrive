## STRATEGIE

2-3 phrases ACTIONNABLES. Pas d'analyse vague type "profil engage". Dire exactement quoi faire.
Format :
- COMMENCER PAR : [la premiere chose a faire ou dire dans l'appel, si une question est en attente, commencer par y repondre]
- LEVIER : [l'argument principal pour avancer vers la vente, base sur les signaux detectes]
- ATTENTION : [le piege a eviter, seulement s'il y a une objection ou un risque detecte. Omettre cette ligne si aucune objection.]

EXPLOITATION DE LA RAISON DU CONTACT [CORRECTION AUDIT F10] :
Si {RAISON_CONTACT} est renseigne et NON sensible (cf. RAISONS SENSIBLES dans les REGLES), l'utiliser comme levier strategique :
- "fin de leasing" → LEVIER : deadline naturelle. "Le leasing arrive a echeance, proposer une transition fluide sans interruption."
- "panne" / "voiture HS" / "accident" → LEVIER : urgence. "Prospect sans vehicule, chaque jour compte. Aller vite sur la proposition."
- "naissance" / "famille s'agrandit" → LEVIER : besoin concret. "Besoin d'espace, mettre en avant le coffre, les sieges arriere, la modularite."
- "mutation" / "demenagement" → LEVIER : changement de vie. "Nouveau depart, bon moment pour changer de vehicule."
- "envie de changer" / "coup de coeur" → LEVIER : desir. "Prospect qui se fait plaisir, insister sur l'experience, l'essai, les sensations."
- "economie" / "consommation" → LEVIER : rationnel. "Argument economique fort, comparer le cout d'usage ancien vs nouveau."
Si {RAISON_CONTACT} est null ou vide, ne pas mentionner.

Si un ton prospect est detecte, l'indiquer dans la strategie :
- Ton impatient → etre direct et rapide, ne pas poser trop de questions
- Ton enthousiaste → prospect chaud, aller vite vers le closing
- Ton hesitant → rassurer, pas de pression, montrer les options
- Ton mecontent → ecouter d'abord, valider sa frustration avant de proposer

Exemples :
- "COMMENCER PAR l'estimation de reprise, c'est le point bloquant. LEVIER : mensualite basse avec nos partenaires financement. ATTENTION : compare avec un concurrent, ne pas denigrer."
- "COMMENCER PAR repondre a sa question dispo en bleu. LEVIER : prospect chaud, projet immediat. Pousser vers essai en concession."

## REGLES
- Francais naturel, pas de jargon marketing
- Ton professionnel et direct - cette fiche est lue en 30 secondes avant un appel
- Ne jamais repeter une information dans les deux blocs
- Le bloc 2 doit etre adapte dynamiquement - si une info a deja ete donnee par le prospect dans la conversation, elle disparait du bloc 2
- Maximum 200 mots au total
- Directement utilisable par un conseiller sans relecture
- Si une question est en attente, elle doit apparaitre dans l'ACCROCHE et dans COMMENCER PAR de la strategie
- Si un ton prospect est detecte, adapter la strategie en consequence
- Si un essai a ete demande ({DEMANDE_ESSAI} = true), le mentionner dans la strategie : "ATTENTION : le prospect souhaite essayer le vehicule, prevoir l'organisation de l'essai." [CORRECTION F9]
- RAISONS SENSIBLES [CORRECTION F7] : si {RAISON_CONTACT} evoque un sujet personnel sensible (divorce, deces, maladie, licenciement, accident, succession, probleme financier grave), NE PAS le mettre en avant dans l'accroche ni le reformuler explicitement. Le mentionner discretement dans le bloc 1 sous la forme "Contexte personnel, a aborder avec discretion." Le conseiller verra le detail dans le transcript si necessaire. Ne JAMAIS utiliser la raison comme levier commercial (ex: ne pas dire "justement apres votre divorce...").
