## 6. CRÉER LE SERVICE

Créer FeedbackRdvService avec :

```java
@Service
@RequiredArgsConstructor
public class FeedbackRdvService {

    private final FeedbackRdvRepository feedbackRdvRepository;
    private final AuthService authService;

    // Définition des paliers
    private static final int[][] PALIERS = {
        {0, 4},    // 🌱 Premiers pas
        {5, 14},   // 🌿 En croissance
        {15, 29},  // 🌳 Fiable
        {30, 49},  // ⭐ Expert
        {50, Integer.MAX_VALUE} // 🏆 Maître
    };
    private static final String[] PALIERS_EMOJI = {"🌱", "🌿", "🌳", "⭐", "🏆"};
    private static final String[] PALIERS_NOM = {"Premiers pas", "En croissance", "Fiable", "Expert", "Maître"};
    private static final String[] PALIERS_DESC = {
        "Votre IA commence à apprendre",
        "Votre IA prend ses marques",
        "Votre IA vous connaît bien",
        "Votre IA est affûtée",
        "Votre IA est redoutable"
    };

    // Seuil minimum pour afficher le % de précision
    private static final int SEUIL_PRECISION_VISIBLE = 20;

    @Transactional
    public RepFeedbackRdvDto enregistrerFeedback(ReqFeedbackRdvDto request) {
        Long tenantId = authService.getCurrentTenantId();
        Long vendeurId = authService.getCurrentUserId();

        FeedbackRdv feedback = new FeedbackRdv();
        feedback.setTenantId(tenantId);
        feedback.setLeadId(request.getLeadId());
        feedback.setRdvId(request.getRdvId());
        feedback.setVendeurId(vendeurId);
        feedback.setQualiteAppel(QualiteQualificationEnum.valueOf(request.getQualiteAppel()));
        feedback.setSuitePrevue(SuitePrevueEnum.valueOf(request.getSuitePrevue()));

        feedbackRdvRepository.save(feedback);

        // Calculer les infos de palier
        long total = feedbackRdvRepository.countByTenantIdAndQualiteAppelIsNotNull(tenantId);
        int totalInt = (int) total;

        // Trouver le palier actuel
        int palierIndex = 0;
        for (int i = 0; i < PALIERS.length; i++) {
            if (totalInt >= PALIERS[i][0] && totalInt <= PALIERS[i][1]) {
                palierIndex = i;
                break;
            }
        }

        // Calculer feedbacks restants pour prochain palier
        int feedbacksRestants = 0;
        String palierSuivant = null;
        if (palierIndex < PALIERS.length - 1) {
            feedbacksRestants = PALIERS[palierIndex + 1][0] - totalInt;
            palierSuivant = PALIERS_EMOJI[palierIndex + 1] + " " + PALIERS_NOM[palierIndex + 1];
        }

        // Précision IA : uniquement si assez de données
        boolean precisionVisible = totalInt >= SEUIL_PRECISION_VISIBLE;
        int precision = precisionVisible ? calculerPrecisionIa(tenantId) : 0;

        return RepFeedbackRdvDto.builder()
                .feedbackId(feedback.getId())
                .totalFeedbacks(totalInt)
                .precisionIa(precision)
                .precisionVisible(precisionVisible)
                .palierActuel(PALIERS_EMOJI[palierIndex] + " " + PALIERS_NOM[palierIndex])
                .palierSuivant(palierSuivant)
                .feedbacksRestantsPalier(feedbacksRestants)
                .build();
    }

    @Transactional
    public void enregistrerAbandon(ReqAbandonRdvDto request) {
        Long tenantId = authService.getCurrentTenantId();
        Long vendeurId = authService.getCurrentUserId();

        FeedbackRdv feedback = new FeedbackRdv();
        feedback.setTenantId(tenantId);
        feedback.setLeadId(request.getLeadId());
        feedback.setRdvId(request.getRdvId());
        feedback.setVendeurId(vendeurId);
        feedback.setRaisonAbandon(RaisonAbandonEnum.valueOf(request.getRaisonAbandon()));

        feedbackRdvRepository.save(feedback);
    }

    @Transactional(readOnly = true)
    public int calculerPrecisionIa(Long tenantId) {
        long positifs = feedbackRdvRepository.countByTenantIdAndQualiteAppelIn(
                tenantId, List.of(QualiteQualificationEnum.CHAUD, QualiteQualificationEnum.OK));
        long total = feedbackRdvRepository.countByTenantIdAndQualiteAppelIsNotNull(tenantId);
        if (total == 0) return 0;
        return (int) Math.round((double) positifs / total * 100);
    }

    @Transactional(readOnly = true)
    public Map<String, Object> getStatsPrecision(Long tenantId) {
        long total = feedbackRdvRepository.countByTenantIdAndQualiteAppelIsNotNull(tenantId);
        int totalInt = (int) total;
        boolean precisionVisible = totalInt >= SEUIL_PRECISION_VISIBLE;

        Map<String, Object> stats = new HashMap<>();
        stats.put("totalFeedbacks", totalInt);
        stats.put("precisionVisible", precisionVisible);

        if (precisionVisible) {
            stats.put("precisionIa", calculerPrecisionIa(tenantId));
        }

        // Palier actuel
        int palierIndex = 0;
        for (int i = 0; i < PALIERS.length; i++) {
            if (totalInt >= PALIERS[i][0] && totalInt <= PALIERS[i][1]) {
                palierIndex = i;
                break;
            }
        }
        stats.put("palierActuel", PALIERS_EMOJI[palierIndex] + " " + PALIERS_NOM[palierIndex]);
        stats.put("palierDescription", PALIERS_DESC[palierIndex]);

        return stats;
    }
}
```

## 7. CRÉER LE CONTROLLER

Ajouter les endpoints dans le controller existant qui gère les RDV, ou créer un nouveau :

```java
@RestController
@RequestMapping("/api/feedback")
@RequiredArgsConstructor
@PreAuthorize("isAuthenticated()")
public class FeedbackRdvController {

    private final FeedbackRdvService feedbackRdvService;
    private final AuthService authService;

    @PostMapping("/rdv")
    public RepFeedbackRdvDto feedbackRdv(@RequestBody @Valid ReqFeedbackRdvDto request) {
        return feedbackRdvService.enregistrerFeedback(request);
    }

    @PostMapping("/abandon")
    public ResponseEntity<Void> abandonRdv(@RequestBody @Valid ReqAbandonRdvDto request) {
        feedbackRdvService.enregistrerAbandon(request);
        return ResponseEntity.ok().build();
    }

    @GetMapping("/precision-ia")
    public Map<String, Object> precisionIa() {
        Long tenantId = authService.getCurrentTenantId();
        return feedbackRdvService.getStatsPrecision(tenantId);
    }
}
```

## 16. NOTIFICATION D'IMPACT APRÈS FEEDBACK NÉGATIF

Quand un vendeur donne un feedback 😕 "À côté", il doit VOIR que son retour a eu un impact.

Implémentation côté BACKEND :
- Ajouter un champ `impact_notifie` (BOOLEAN DEFAULT FALSE) à la table feedback_rdv
- Créer un endpoint GET /api/feedback/impacts-en-attente qui retourne les feedbacks 😕 de plus de 7 jours pour lesquels impact_notifie = false
- Créer un endpoint POST /api/feedback/{id}/impact-vu pour marquer la notification comme vue

Implémentation côté FRONTEND :
- Au chargement du dashboard vendeur, appeler GET /api/feedback/impacts-en-attente
- Pour chaque impact non notifié, afficher une notification toast ou une petite card :
  - Style : fond vert clair, icône ✅
  - Texte : "Suite à votre retour sur {nomProspect}, l'IA ajuste ses critères de qualification. Merci !"
  - Bouton "OK" ou auto-dismiss après 5 secondes
  - Au dismiss, appeler POST /api/feedback/{id}/impact-vu
- Maximum 1 notification affichée à la fois (les autres en file d'attente)
- Ne s'affiche qu'UNE SEULE FOIS par feedback

⚠️ NOTE : au Niveau 1 (MVP), l'IA n'ajuste pas réellement ses critères (c'est le Niveau 3). Le message est formulé au futur proche ("ajuste ses critères") ce qui est honnête, les données sont collectées et SERONT utilisées. Ne PAS dire "l'IA s'est améliorée" si ce n'est pas encore le cas.

Message alternatif plus honnête si on préfère :
"Votre retour sur {nomProspect} a été enregistré. Il sera utilisé pour affiner la qualification IA de votre concession."
